Compare and format JSON side by side in your IDE with JsonDiffTool. All JSON content is processed locally.

Key features

  • Automatic formatting: format JSON after pasting or editing, or format both sides manually.
  • Difference highlighting: highlight additions, deletions, and changes, with difference navigation and synchronized scrolling.
  • Validation and key sorting: report invalid JSON and duplicate keys; sort object keys to remove differences caused by key order.

Getting started

  1. Open a project and select Tools > JsonDiffTool.
  2. Paste JSON into the left and right editors and wait for automatic formatting.
  3. Review the highlighted differences and use the previous and next difference buttons to navigate.

JsonDiffTool (Android Studio / IntelliJ Platform)：在 IDE 中自动格式化 JSON，并排查看两组数据的差异。所有内容在本地处理。

核心功能

  • 自动格式化：粘贴或编辑 JSON 后自动整理缩进，也可手动格式化。
  • 差异高亮：实时标记新增、删除与修改，支持差异跳转和同步滚动。
  • 辅助校验：提示格式错误和重复键；可按对象键排序，排除键顺序造成的差异。

快速上手

  1. 打开项目，在 Tools 菜单中选择 JsonDiffTool。
  2. 在左右两侧分别粘贴 JSON，等待自动格式化。
  3. 查看高亮，通过上一处、下一处差异按钮逐项检查。
